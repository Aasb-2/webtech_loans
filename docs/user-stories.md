# Roomies - System Documentation

## 1. User Stories

### Visitor
* As a Visitor, I want to browse published room listings so that I can explore available housing without logging in.
* As a Visitor, I want to filter listings by price, neighborhood, and amenities so that I can quickly narrow down relevant options.
* As a Visitor, I want to register for a new account so that I can start hosting or applying for rooms.

### Member (Seeker)
* As a Seeker, I want to submit an application with my intended move-in date and stay duration so that the host can evaluate my request.
* As a Seeker, I want to schedule a visit for a property so that I can inspect the space in person.
* As a Seeker, I want to leave a review and rating for a property after completing a visit so that I can share feedback with the community.

### Member (Host)
* As a Host, I want to create and publish listing drafts with details like rent, deposit, and photos so that seekers can find my property.
* As a Host, I want to manage listing status transitions (e.g., set to Published, Reserved, or Rented) so that the listing reflects current availability.
* As a Host, I want to accept or reject applications so that I can select the best candidate for my space.

### Moderator
* As a Moderator, I want to view reported listings and reviews so that I can ensure content meets platform standards.
* As a Moderator, I want to flag or remove inappropriate users or listings so that the platform remains safe for everyone.
